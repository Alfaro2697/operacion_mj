# Operación MJ — Cómic romántico (Bootstrap 5)

- `vista-previa.html`: prueba el diseño con navegación entre todas las pantallas (solo para revisar).
- `index.html`: versión de la página para publicar, sin barra de navegación de prueba.
- `comic-romance.css`: tema nuevo de historieta, se carga después de Bootstrap y `styles.css`.
- `styles.css`: estilos existentes; `script.js`: lógica existente.
- `assets/`: fotografías, video y música.
- `vendor/`: Bootstrap local.

Para GitHub Pages, sube **index.html, styles.css, comic-romance.css, script.js, assets y vendor** a la raíz del repositorio. No subas `vista-previa.html` si no deseas que terceros puedan saltarse las preguntas; de todos modos esta página no es un sistema real de seguridad ni hace privada una web pública.

El contador guarda la fecha en el mismo navegador. Una fecha idéntica en todos los dispositivos requiere fijar la fecha definitiva o un servicio compartido.
